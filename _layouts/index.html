Install

Run it from a clone

Clone the repository, install the pinned requirements and put your Azure keys in a .env file. Audio Analyser needs Python 3.10 or newer, and PortAudio for recording.

  • python -m audioanalyser -s
  • python -m audioanalyser -sum
Read the getting started guide
Security

Your keys, your files

Audio Analyser runs on your machine and sends audio and text only to the services you configure.

Keys live in a local .env file. Audio goes to Azure for transcription; transcripts go to Azure for analysis and to the language-model provider you choose, or nowhere at all with Ollama. The security page lists every outbound call.
